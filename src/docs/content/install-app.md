# Install AMVerge

Install the AMVerge desktop app on Windows or macOS.

## Install on Windows

1. Download the latest installer from [amverge.app](https://amverge.app).
2. Run the installer.
3. If Windows SmartScreen appears, click **More info**, then **Run anyway**.
4. Open AMVerge from the Start menu.

> **Note:** SmartScreen warns about apps from publishers Windows doesn't recognize yet. It's common for independent apps. AMVerge is [open source](https://github.com/AMVerge-team/AMVerge), so anyone can read the code. Only download it from amverge.app or our GitHub.

## Install on macOS

1. Download the latest `.dmg` from our [GitHub releases](https://github.com/AMVerge-team/AMVerge/releases).
2. Open the `.dmg`.
3. Drag AMVerge into your **Applications** folder.

## Updates

AMVerge checks for updates when it starts and asks before installing one.

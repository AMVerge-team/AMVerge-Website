# Quick Start

In this guide, you import an episode, select a few scenes and export them as clips.

## Before you begin

- [Install AMVerge](/docs/install-app).
- Have a video file ready. See [supported formats](/docs/import-episodes#supported-formats).

## Steps

### 1. Import an episode

Click **Import** and choose a video, or drag the file into the window.

AMVerge detects the scenes and shows each one as a tile in the grid.

### 2. Preview scenes

Hover over a tile to play it. Click a tile to play it in the preview panel.

### 3. Select the clips you want

- **Ctrl + Click** selects individual clips.
- **Shift + Click** selects a range.

On macOS, use **Cmd** instead of **Ctrl**.

### 4. Export

1. Choose a destination folder in the export panel.
2. Choose an export profile. **Default MP4** works in most editors.
3. Click **Export Now**.

AMVerge saves your clips and opens the folder.

# Import Episodes

When you import a video, AMVerge finds its scenes and creates a preview for each one.

## Import a video

Click **Import** and choose one or more videos, or drag them into the window. If you import several at once, AMVerge processes them in order.

## Choose a detection method

Set this in **Settings > General > Scene Detection Method**.

| Method | Best for | Requires |
|---|---|---|
| **Keyframe Detection** | Speed. Nearly instant, and works on any PC | Nothing extra |
| **AI Scene Detection** | Accuracy. Cuts land right on the scene change | [AI download](/docs/ai-features). A GPU is recommended |

Keyframe detection cuts at the video's keyframes, so its results depend on how the video was encoded. If you see scenes that are cut in the wrong place, try AI scene detection.

## Choose a preview type

Set this in **Settings > General > Preview Method**.

| Preview type | What it does | Best for |
|---|---|---|
| **Video Files** | Cuts a real video clip per scene | Most PCs |
| **WebP Files** | Makes small animated previews instead | Lower-end PCs |

## Supported formats

AMVerge imports MP4, MKV, MOV, WebM, AVI, M4V and TS files.

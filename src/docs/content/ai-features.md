# Turn On AI Features

AMVerge works fully without AI. The AI features are off until you turn them on, and they're free.

## Available features

| Feature | What it does |
|---|---|
| **AI Scene Detection** | Finds scene cuts with TransNetV2, the most accurate way to import |
| **Scene Scout** | Searches your episodes by description |
| **Depth Map Pass** | Creates a depth map of your exported files |

## Turn on a feature

1. Open **Settings > Features**.
2. Turn on the feature.
3. Wait for the download to finish.

## GPU decoding

When AI Scene Detection is on, **Settings > General** also offers **GPU Decoding**, which speeds up detection on supported GPUs.

## Free up space

Turning a feature off keeps its files. To remove them, use **Free up space** in **Settings > Features**. The **Storage** section there shows how much space each part uses.

> **Note:** Scene Scout's model is stored in the shared Hugging Face cache, which other apps can use too. AMVerge counts it but never deletes it.
